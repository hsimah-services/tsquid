# @tsquid/routes

Runtime for routes generated by [`@tsquid/codegen`](https://www.npmjs.com/package/@tsquid/codegen):
typed URIs, route context, Relay entrypoint loading, preloading links.

Peers: `react` 19, `react-router` 8, `react-relay` / `relay-runtime` 21.

## Config

`routes.json` declares the URL shape. The entrypoint module declares behaviour
(`getRouteType`, `getPreloadProps`).

```json
{
  "runtime": "@tsquid/routes",
  "routes": [{
    "name": "ArticleSearch",
    "entryPoint": "src/components/article/Article.entrypoint.ts",
    "path": "/articles/:section",
    "fields": {
      "section": { "kind": "string" },
      "page": { "kind": "int", "optional": true },
      "tags": { "kind": "string[]", "optional": true },
      "drafts": { "kind": "bool", "optional": true }
    }
  }]
}
```

```sh
tsquid-codegen routes.json src/routes/__generated__/routes.ts [--check]
```

- Kinds: `string`, `int` (safe integer), `bool`, and `[]` arrays of each.
- Path fields are required scalars. Every other field is a query parameter.
- Arrays are repeated keys: order and duplicates are preserved. An empty optional
  array is omitted; a required array must be non-empty.
- Invalid values, duplicate scalar keys, missing required fields and bad path
  encoding throw. Nothing is coerced.
- An optional path segment is modelled as a separate route.
- `entryPoint` is a normalized path relative to the config, named
  `<Name>.entrypoint.ts`. Basenames must be unique.

## Generated API

For each route: `<Route>InputType`, `<Route>URI` and `<Route>RouteContext`.
For each entrypoint module: `use<Name>RouteContext()`. Across the catalogue: the
`RouteName` enum.

```ts
ArticleSearchURI.getURI({ section: 'a/b', tags: ['x', 'y'] }); // '/articles/a%2Fb?tags=x&tags=y'
ArticleSearchURI.parseURI('/articles/news?drafts=false');      // { section: 'news', drafts: false }

const route = useArticleRouteContext();                        // union of the module's routes
if (route.currentRoute === RouteName.ArticleSearch) {
  navigate(route.updateURI({ page: 2 }));                      // narrowed to ArticleSearch fields
}
```

- `getURI` builds a URL from explicit input and works from anywhere.
- `updateURI(patch)` exists only on the active route context. It merges the patch
  into the current location, removes keys set to `undefined`, and keeps query keys
  the route doesn't own, plus the hash. It returns a string; it doesn't navigate.
- `use<Name>RouteContext()` throws outside a provider, or when another entrypoint
  is active. `<Route>RouteContext.useRoute()` requires that exact route.
- One context per catalogue, so the nearest route provider wins.

## Entrypoints

```ts
export const ARTICLE_ENTRY_POINT: RouteEntryPoint<RouteType, Queries, Nested, RuntimeProps, ExtraProps> = {
  root: resource('ArticlePage', ArticleEntryPoint),
  getPreloadProps: route => ({
    queries: { search: { parameters: ArticleSearchQuery, variables: { section: route.section } } },
  }),
};

export const ARTICLE_ROUTES = {
  search: defineRoute({
    uri: ArticleSearchURI,
    context: ArticleSearchRouteContext,
    getRouteType: input => ({ ...input, tags: new Set(input.tags ?? []) }),
    entryPoint: ARTICLE_ENTRY_POINT,
  }),
};
```

- `RouteEntryPoint` types Relay's `root` + `getPreloadProps` contract. Relay's own
  `EntryPoint` types are circular and fail under TS7; runtime behaviour is Relay's.
- `getPreloadProps` returns `queries`, `entryPoints` (nested: `entryPoint` +
  `entryPointParams`) and optional `extraProps`. Make keys optional in their type
  to omit them conditionally.
- `EntryPointProps<Queries, Nested, RuntimeProps, ExtraProps>` types the root
  component's props. Render nested references with `RouteEntryPointContainer`.
- `resource(id, Component)` wraps an eager component. For a lazy one, implement
  `JSResourceReference`.
- `getRouteType` maps URL input to any type (sets, enums, dates).
- `defineRoute(...).Root` is the router component; mount it under
  `RelayEnvironmentProvider`. It accepts `fallback`. It loads with
  `useEntryPointLoader` (disposed on replace and unmount); errors reach the
  router's error boundary. `useRouteType()` reads the derived route type.

## Links

```ts
const AppLink = createLink([ARTICLE_ROUTES.search, ...]);
```

- A React Router `Link` that preloads the matching route's entrypoint graph on
  hover and focus. Routes are matched in order, so put static paths before
  dynamic ones that conflict.
- Preloading uses `fetchQuery` plus `retain`, per Relay's
  [retention contract](https://relay.dev/docs/api-reference/fetch-query/). It is
  released on destination or environment change, on unmount, or after 30 s.
  Duplicate requests are deduplicated by Relay.
- Skipped for external links, downloads, `reloadDocument`, non-`_self` targets and
  `preventDefault`. Preload errors are swallowed; navigation retries.
- Requires concrete query artifacts (not preloadable IDs) and a single Relay
  environment. A cyclic entrypoint graph throws and releases what it acquired.
